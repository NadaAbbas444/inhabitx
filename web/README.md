# Web page

`index.html` mirrors the master screen for anyone online: **Overview** (free rooms, floor plan), **Campus map**, **Book a room**, **Lost & Found**. Plain HTML + `mqtt.js` + Leaflet, no build step. GitHub Pages serves this folder (`.github/workflows/pages.yml`).

- `floorplan.js` is generated by `firmware/master/assets/gen_floorplan.py` (same plan as the screen). Don't edit it by hand.
- Open `index.html?demo` (or leave `CONFIG.brokerUrl` empty) for a demo building that behaves like the master's simulator.
- Map tiles: © OpenStreetMap contributors. The floor plan is traced by eye from the public AAU campus plan (campusplan.aau.at, floor 1); accuracy about ±0.5 m.

## Configuration

At the top of the script in `index.html`:

| Field | Value |
|---|---|
| `brokerUrl` | `wss://<cluster>.s1.eu.hivemq.cloud:8884/mqtt` |
| `readUser` / `readPass` | read-only login: building state + lost & found |
| `sendUser` / `sendPass` | send-only login for booking and found reports. Empty = booking stays in demo mode |
| `ghostMinutes` | must match the master's release time |

### Read (login `web`, read-only)

`inhabitx/<b>/rooms` (retained). As in README §4, plus three **optional** fields the page uses when present:

```json
{"ts": 1764237600, "rooms": [
  {"id": "Z.1.10", "state": "free", "free_until": "14:00",
   "seats": 6, "floor": 1, "slots": [["14:00", "15:00"]]}
]}
```

- `seats`, `floor`: otherwise the page falls back to its own table.
- `slots`: today's booked times **without names**, used for the booking bars and for greying out clashes.

`inhabitx/<b>/lostfound` (retained):

```json
{"ts": 1764237600, "items": [{"room": "Z.1.10", "cat": "umbrella", "ts": 1764234000, "online": false}]}
```

`cat` is one of `phone keys wallet bag bottle clothing electronics umbrella glasses other`. `online: true` = reported on the web and not confirmed at the desk yet. Items older than 7 days are dropped by the master.

### Send (login `webhook`: write `inhabitx/+/bookings/new` and `inhabitx/+/lostfound/new`, read `inhabitx/+/replies/#`, nothing else)

`inhabitx/<b>/bookings/new`:

```json
{"req": "k3j9x0a1", "room": "Z.1.10", "from": "14:00", "to": "15:00", "people": 4,
 "name": "Yousef", "email": "yousef@edu.aau.at"}
```

`inhabitx/<b>/lostfound/new`:

```json
{"req": "p0c7m2zz", "room": "Z.1.11", "cat": "keys"}
```

The master answers on `inhabitx/<b>/replies/<req>` (not retained):

```json
{"ok": true}
{"ok": false, "error": "overlap"}
```

`error` is one of `name email time seats overlap busy limit full` (same as `ix_book_err_t` on the master). The page gives up after 8 s and tells the user to book at the screen.

### Why this is acceptable

- Name and email travel encrypted (TLS) to the broker and are only readable by the master. They are never retained or published back. The read-only `web` login cannot see them.
- The send login is visible in the page source, so anyone could send fake requests. The master's rules limit the damage: max 2 active bookings per email, and an unused booking is released 10 minutes after its start. Fake found reports are marked "reported online, not yet at the desk".
