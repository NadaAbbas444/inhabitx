# Web page

`index.html` mirrors the main's screen for anyone online: **Overview** (free rooms, floor plan), **Campus map**, **Book a room**, **Lost & Found**. Plain HTML + `mqtt.js` + Leaflet, no build step. GitHub Pages publishes this folder on every push to `main` (`.github/workflows/pages.yml`).

The messages it reads and sends are in [README §3](../README.md#3-messages).

## Configuration

At the top of the script in `index.html`:

| Field | Value |
|---|---|
| `brokerUrl` | `wss://inhabitx-46341c9d.a03.euc1.aws.hivemq.cloud:8884/mqtt` |
| `readUser` / `readPass` | `web`: reads the building state and found items |
| `sendUser` / `sendPass` | `webhook`: sends bookings and found items, reads the replies. Empty = booking stays in demo mode |
| `ghostMinutes` | release time in demo mode only; live, the countdown comes from the main |

Both passwords are public in the page source on purpose; README §7 explains why that's acceptable.

## Notes

- `index.html?demo` (or an empty `brokerUrl`) runs a demo building in the browser, no broker needed.
- Booking hours (`OPEN`, `CLOSE`) must match `IX_DAY_OPEN_H` / `IX_DAY_CLOSE_H` on the main.
- `floorplan.js` is generated by `firmware/main/assets/gen_floorplan.py` (same plan as the screen). Don't edit it by hand.
- Map tiles © OpenStreetMap contributors. The floor plan is traced by eye from the public AAU campus plan (campusplan.aau.at, floor 1), about ±0.5 m.
