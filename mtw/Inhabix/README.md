# InhabitX classroom occupancy firmware

The active CM55 application uses our trained classroom model (unlabeled/background/human_activity), with native E84 PDM capture and occupancy filtering. It no longer runs the upstream baby-cry classifier.

See [the application guide](../README.md) for build instructions, UART output, behavior, validation status, and integration limits. The historical Infineon example instructions are retained in [README.upstream.md](README.upstream.md).
